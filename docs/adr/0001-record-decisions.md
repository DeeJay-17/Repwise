# 0001. Record architecture decisions

- Status: accepted
- Date: 2026-11-16

## Context

Repwise is built by one developer over several months. Reasons for early choices are easy to forget, and the repo is also a portfolio piece where the reasoning matters.

## Decision

Keep a short decision record in `docs/adr` for each significant choice, numbered in order, using `0000-template.md`. A record is never edited after acceptance; a later record supersedes it.

## Consequences

A few minutes per decision. Anyone reading the repo can see why it looks the way it does.
